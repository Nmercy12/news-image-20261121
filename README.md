Entry for the [news-image-20261121 bounty](https://make.fun/bounty/news-image-20261121) on make.fun.

This entry is a Python program that uses PIL to draw a 1024x1024 newspaper front page summing up Saturday 21 November 2026 world news — 38 dated stories across 7 regions, with a KPI strip, a UTC timeline, verification badges and a DATE CHECK box. The drawing is fully deterministic: no randomness, timestamps or environment-dependent values, so every run produces byte-identical output.

## Run

```sh
python3 main.py
```

The program writes `entry.png` (to `/output` when available, otherwise to `out/entry.png` next to `main.py`).
